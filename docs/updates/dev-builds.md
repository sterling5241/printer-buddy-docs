# Dev/beta builds

You can try the newest build of **one part** while everything else stays stable.

## Switching one part

1. Open **☰** on the home page and scroll to **Updates**.
2. **Press and hold** the part's name for half a second (or **right-click** it).
3. Tick **Dev/beta builds** and confirm.

That part downloads its nightly build and Printer Buddy restarts. Parts on dev show an orange **DEV** tag.

Putting **Printer Buddy** itself on dev moves the core app to the newest code too.

## Going back

Hold the name again and untick **Dev/beta builds**. The part goes back to its stable version.

## Good to know

!!! warning
    Dev builds are newer and haven't been tested as much. If something breaks, switch the part back to stable.
